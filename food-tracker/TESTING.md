# Phone test checklist

Plain steps. If anything looks wrong, take a screenshot and send it to Andrew.

## Phase 1: Can you get in?

Use your phone. Try it once on cellular and once on Wi-Fi if you can.

1. Open **https://food.pivotaiglobal.com** in Safari (iPhone) or Chrome (Android).
2. You should see a Cloudflare page asking for your email. Type your email and tap the button.
3. Check your email for a 6-digit code. It comes from Cloudflare. Look in spam if it's not there in a minute.
4. Type the code on the phone. You should land on a page that says **Hello,** and your email.
5. Under that, you should see two green checks: **Sign-in works** and **Database connected**.
6. Close the browser tab completely, then open the link again. You should go straight in, no code this time.
7. Tap **Sign out**. Open the link again. It should ask for your email again.
8. Optional: in Safari, tap Share > **Add to Home Screen**. Open it from the icon. Same Hello page.
9. Optional: switch your phone to dark mode. The page should turn dark and still be easy to read.

### Things that should NOT work

10. Ask someone whose email is not on the list to open the link and try. They should not get a code that works, and should never see the Hello page.

### Tell Andrew

- Did every step above match? If not, which number?
- How long did the code email take to arrive?
- Anything confusing on any screen?
